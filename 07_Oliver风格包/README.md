# Oliver 风格包（个人网站 / 样品页 / 封面通用）

日期：2026-10-12 ｜ 线上效果：https://oliverouyang.vercel.app
预览：用浏览器打开 `preview.html`（需联网加载 Google Fonts）

> 这是公开仓库里的副本。工作版在 Freelancer 项目共享文件夹 `upwork/website/brand-kit/`。
> 下表里的 `photo/`（本人照片）和 `fonts-private/`（平方江南体字体文件）**故意没放进这个仓库**：照片是个人隐私，字体作者没有授权再分发。
> 风格包里的 CSS、SVG、模板是原创，© Oliver Ouyang；用到的 Google 字体都是 OFL 1.1。

## 概念
“分析师批改过的报告”：干净的浅底和黑字是“报告”，荧光笔、手写批注和手绘箭头是“Oliver 本人在旁边做的批改”。手绘层负责活人感，报告层负责专业感，两层都要有。

## 文件
| 文件 | 用途 |
|---|---|
| `tokens.css` | 字体、颜色、圆角、字号变量（`--oo-*`），引入 Google Fonts |
| `hand.css` | 手绘层：荧光笔 `.oo-mark`、手写批注 `.oo-note`、自动画出的下划线和圈 `.oo-draw`、分步箭头 `.oo-draw-on`、步骤状态 `.oo-step`、弹出 `.oo-pop`、晃动 `.oo-wiggle`、按钮 `.oo-btn` |
| `svg/` | 6 个手绘元素：下划线、圈、右箭头、弯箭头、对勾、强调光芒。网页里要动画就把 path 内联并加 `.oo-draw`；封面和静态图直接用 SVG 文件 |
| `photo/` | 本人照片（**不在本仓库**，只在项目共享文件夹）：`avatar.jpg`（`.oo-avatar`）和 `portrait.jpg`（`.oo-portrait`），网站和封面共用 |
| `templates/` | 封面（Fiverr / Upwork / 闲鱼）和图集模板，参数写在网址里，`render.js` 出图；说明见 `templates/README.md` |
| `fonts-private/` | 平方江南体字体文件和授权说明（**不在本仓库**），只在本机渲染用，不上网站。没有它时模板自动退回马善政 |
| `preview.html` | 所有元素的效果预览，可以照抄代码 |

## 规则（必须）
- 英文字体只用两种：Schibsted Grotesk（标题和正文）、Sedgwick Ave（只用于手写批注，常规字重，字号 18–25px；Oliver 2026-10-11 选定）
- 中文（国内平台：闲鱼等）：标题正文用思源黑体 Noto Sans SC；手写批注用**平方江南体**（Oliver 2026-10-12 选定），和 Sedgwick Ave 配对，英文和数字仍由 Sedgwick Ave 显示。见下方“中文字体和授权”
- 颜色：纸色底 #F4F4F1、墨色 #141414；强调只用荧光黄 #FFE45C 和墨绿 #1B6B3F；红色 #B3261E 只表示出错
- 圆角统一 6px，边框统一 1.5px 墨色
- 每屏 1–2 句手写批注，写成 Oliver 本人会说的话（口语、短、可以有箭头），说清“为什么值得看”，不要重复正文
- 每页只有一个荧光笔重点、一个元素在晃动
- 展示要用真实的东西：截图、录屏、能点的 demo；样品标 “Sample · fictional shop”
- 动画只服务于“看懂流程”：画箭头、点亮步骤、弹出结果；所有动画已适配“减少动效”

## 规则（不要）
- 不用标题上方的小胶囊标签、编号小标题（01 / 02）、一排相同的图标卡片、大圆角、渐变、emoji
- 不用 Inter、Roboto、Arial，不用紫色
- 不用 “actionable insights”“seamless”“resilient” 这类 AI 腔词
- 不放邮箱、微信等联系方式
- 不用 AI 生成的“手绘”图片冒充手绘：手绘元素都用这里的 SVG 路径
- 不给 Sedgwick Ave 加粗或斜体（只有一个字重，浏览器会假加粗）

## 用在各处
- **样品展示页（P1–P4）**：首屏 = 标题 + 一句荧光笔结果 + 1 分钟讲解视频（视频优先规则）+ 一句手写批注；之后用 `.oo-step` 做“它怎么运作”的分步区；结尾一个按钮回平台
- **封面图（Upwork 1000×750 / Fiverr 1280×769）**：纸色底，左边 ≤10 个词的大标题（荧光笔压在关键词下），右边一张真实结果截图加 1.5px 墨色边框，截图上用一个手绘圈或箭头 + 一句 Sedgwick Ave 批注指向重点
- **讲解视频**：片头标题卡同封面；关键时刻在画面上叠手绘圈或箭头（可用 svg 文件），字幕用 Schibsted Grotesk
- **交付文档 / PDF**：标题用 Schibsted Grotesk 800，正文 400；每页最多一句手写批注做提示
