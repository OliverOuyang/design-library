## 实现者不应猜测的内容

- [ ] 页面与 Frame 命名清楚，版本和范围已冻结。
- [ ] 变量、组件、变体与代码 / 文档映射明确。
- [ ] 加载、空、错误、权限、离线、禁用、成功、撤销和破坏性状态齐全。
- [ ] 响应式、平台差异、键盘 / 焦点、减少动态效果和长内容有说明。
- [ ] 文案、数据格式、图片裁切、动画时序、图标与导出规格可追踪。
- [ ] 第三方资产来源、许可证和使用边界已核验。

## 独立产出审核

- 审核任务 / 审核人：〔不得是实施任务或过程审核任务〕

- 检查：用户任务、全状态、真实内容、Taste、细节一致性、平台 / 响应式、可访问性、可实现性。
