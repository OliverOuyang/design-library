## 主流程

```text
触发 → 进入 → 理解 / 选择 → 操作 → 系统反馈 → 完成 / 可撤销
                    ↘ 异常 → 解释原因 → 可恢复动作
```

对每一步记录：用户意图、所需信息、可执行动作、系统反馈、数据或权限前提、退出与恢复方式。
