## 使用边界

- 本库不是“拿来即上生产”的通用组件包。先确认动作语义、平台约束、静音/减少动态偏好和连续触发负担。
- `音效/` 中的 WAV 来自 Kenney UI Audio，随附 CC0 许可证；仍应在具体项目中记录采用范围。
- `动效/` 中的 CSS motion 是可单独打开的本库种子样本；预览页由 `assets-manifest.js` 生成，可复制、裁剪和改色。它们用于研究节奏与反馈，不替代真实产品的无障碍测试。
- 新素材进入本目录前，先补齐来源、许可证、哈希、分类、用途和“为什么值得留”；字段定义见 [素材清单与许可.md](素材清单与许可.md)。

## 扩充门槛

只有满足以下条件的条目才进入正式素材层：可本地播放或运行、来源与权利可核验、与现有样本不重复、能写出一个迁移场景。每个新增最小分类必须一次性达到至少 5 项；未满 5 项的候选先留在 `00_收件箱`。
