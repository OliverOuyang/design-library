# 米白层次 · Shades of Off-white

米白/象牙/奶油色极简：用带温度的非纯白做底，大量留白、克制排版和自然材质，营造安静、高级、纸质感的界面与画面。

> 用之前先对照 [不要做原则](../../../04_规则与模板/不要做原则.md)：§1 AI 味严重（网页默认模板）、§7 独立站专项。

## 公开提示词（4 条，原文照抄，附出处）

标「节选」的只抄到了开头，全文看出处。用的时候把主体换成你的，风格约束部分保留。

**1. Gemini 2.5 Flash Image（Nano Banana）** · [出处](https://developers.googleblog.com/en/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/)

```
A minimalist composition featuring a single, delicate red maple leaf positioned in the bottom-right of the frame. The background is a vast, empty off-white canvas, creating significant negative space for text. Soft, diffused lighting from the top left. Square image.
```

Google 官方提示指南第 5 类“极简与负空间”示例：明确主体位置、off-white 背景、给文字留白、光线方向和画幅，可直接改主体复用。

**2. Gemini 2.5 Flash Image（Nano Banana）** · [出处](https://developers.googleblog.com/en/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/)

```
A minimalist composition featuring a single [subject] positioned in the [bottom-right/top-left/etc.] of the frame.
```

节选：同一节模板的首句原文；后续为空背景制造负空间、柔和光线、画幅占位（见来源）。

**3. Midjourney v6.1** · [出处](https://midlibrary.io/styles/minimalism)

```
Minimalism --v 6.1
```

Midlibrary 词条：几何/抽象形体、柔和粉彩与低饱和色、大量负空间；可追加 off-white、ivory 等色彩词收窄。

**4. Midjourney v6.1** · [出处](https://midlibrary.io/styles/wabi-sabi)

```
Wabi-sabi --v 6.1
```

Midlibrary 词条：不完美、纹理、裂痕、土质低饱和色和不对称留白，适合 off-white 中加入手工质感与自然材质。

## 这个风格的「不要做」

- 不要在米白底上用浅灰小字：正文对比度至少 4.5:1（大字 3:1），米白底会进一步降低浅灰文字的对比度，务必实测。（[来源](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html)）
- 不要把 ivory 和 cream 放在相邻元素上：两者都偏暖，挨在一起像“配错色”；要么拉开层级（背景 vs 卡片），要么只用一种。（[来源](https://madegooddesigns.com/ivory-vs-cream-vs-off-white/)）
- 不要把 “off-white” 当成一个颜色：先定冷暖倾向（偏黄/偏粉/偏灰），并让强调色与之匹配，冷白配暖强调色会显得不对劲。（[来源](https://madegooddesigns.com/ivory-vs-cream-vs-off-white/)）
- 需要干净利落的场景不要用偏黄的奶油色，否则会显得陈旧、发黄；奶油色只用于刻意追求温暖感的设计。（[来源](https://madegooddesigns.com/ivory-vs-cream-vs-off-white/)）
- 不要把 Pantone 纺织色号直接当屏幕色：Pantone 官网未给 Cloud Dancer 的 hex，网上的 #F0EEE9 只是近似值，跨屏幕/印刷要实物比对。（[来源](https://www.pantone.com/color-of-the-year/2026)）
