# LOMO 胶片感 · Lomo Imagery

Lomo 风格：LC-A/Holga/Diana 等玩具相机与交叉冲洗、过期胶片带来的高饱和偏色、暗角、漏光、柔焦和“快乐意外”式的随手抓拍感。

## 公开提示词（6 条，原文照抄，附出处）

标「节选」的只抄到了开头，全文看出处。用的时候把主体换成你的，风格约束部分保留。

**1. Midjourney v6.1** · [出处](https://midlibrary.io/styles/lomography)

```
Lomography --v 6.1
```

Midlibrary 风格词条：该风格在 MJ 里默认偏梦幻高饱和、带双重曝光、漏光和动态模糊；需要更克制时要追加具体约束。

**2. Midjourney v6.1** · [出处](https://midlibrary.io/styles/holga-photography)

```
Holga photography --v 6.1
```

Midlibrary 词条：Holga 风格给出暖调、柔焦、漫射光、中心主体、逆光、颗粒和漏光，比 Lomography 更柔和怀旧。

**3. Midjourney v6.1** · [出处](https://midlibrary.io/styles/lomography-color-100)

```
shot in Lomography Color 100 film colors Lomography Color 100 --v 6.1
```

Midlibrary 胶卷型号词条：用具体胶卷名锁定色彩（鲜艳饱和、细颗粒），可替换为 LomoChrome Purple 等其他型号。

**4. Midjourney** · [出处](https://myaiforce.com/midjourney-camera-prompts/)

```
a young woman in a flowy floral dress riding a bicycle down a tree-lined lane, Lomo LC-A
```

MyAIForce 相机提示词对比文：同一场景只换相机名（Lomo LC-A / Instax 等）观察差异，是“主体 + 相机型号”的简洁模板。

**5. Stable Diffusion XL + Toy Camera LoRA** · [出处](https://civarchive.com/models/248225)

```
<lora:Toy_Camera:0.8>, film, bokeh, professional, blur, lomo
```

作者 andreac75 的 SDXL 玩具相机 LoRA 示例；建议权重 0.8 并必须加 lomo 关键词。负面词：big hands, fake, fake hands, distorted, drawing, painting, crayon, sketch, impressionist。页面未注明许可证。

**6. ChatGPT 图像生成（GPT-4o 类）** · [出处](https://academy.techpresso.co/prompts/chatgpt-prompts-lomo-photos)

```
Turn [YOUR PHOTO] into a Lomography portrait: a Lomo cross-process still with green shadows and magenta highlights.
```

节选：这是“Cross Process Green”提示词的首句原文（全文约 361 字符，见来源）。同页 30 条按 LC-A/Holga/偏色/事故/修正分类，均为照片转 lomo 的具体约束写法。

## 这个风格的「不要做」

- 不要给所有画面套同一套“暗角+漏光+偏色”预设：这正是 2011 年 Hipstamatic/Instagram 式“伪复古”被批评的原因，只剩怀旧外壳，失去真实感。（[来源](https://thesocietypages.org/cyborgology/2011/05/14/the-faux-vintage-photo-full-essay-parts-i-ii-and-iii/)）
- 交叉冲洗的偏色不要失控到人脸：Euphoria 摄影师指出交叉冲洗 Ektachrome 需要细致调色；人物镜头应单独校正肤色，偏色留给环境。（[来源](https://www.kodak.com/en/motion/blog-post/euphoria)）
- 别忽略反转片只有约 4–5 档宽容度：高光可以奶油般溢出，但不要整张过曝或阴影全部死黑，关键信息要在宽容度内。（[来源](https://www.kodak.com/en/motion/blog-post/euphoria)）
- 漏光、光斑不要压在主体脸上或铺满全画面；Holga/LC-A 的特征是中心清晰、边缘衰减，漏光多出现在角落或片边。（[来源](https://academy.techpresso.co/prompts/chatgpt-prompts-lomo-photos)）
- 在 Midjourney 里不要只写 “Lomography” 一个词：默认会叠加双重曝光和动态模糊，画面容易过度；需加胶卷型号、相机、构图等具体约束。（[来源](https://midlibrary.io/styles/lomography)）
