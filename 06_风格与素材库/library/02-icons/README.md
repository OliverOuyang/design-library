# 图标

UI 图标和品牌 logo。站点主图标建议 Lucide 或 Phosphor 二选一，保持线宽统一。

## 适合用在

独立站、游戏 UI 菜单、视频字幕旁的小图标。

## 工具 / 资源

| 工具 | 链接 | 许可证 | 用途 | 状态 |

## 按「不要做原则」使用

对应 [不要做原则](../../../04_规则与模板/不要做原则.md)。

- 同一产品只用一套图标（线宽、圆角统一），不要 Lucide 和 Tabler 混用。（§3）
- Lobe Icons 里是别人的商标，只用来指代对应产品。
