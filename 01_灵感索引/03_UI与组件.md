# UI 与组件

重点看真实产品如何解决问题，而不只是看一张“漂亮界面图”。同一个模式至少比较三个产品，再判断什么是共性、什么只是品牌风格。

## 优先入口

| 站点 | 看什么 | 为什么值得留 | 访问 |
|---|---|---|---|
| [Mobbin](https://mobbin.com/) | 真实 App / Web 界面与完整流程 | 可按组件、行业和用户流程找真实产品，不只看概念稿 | 免费预览；完整库需订阅 |
| [Page Flows](https://pageflows.com/) | 用户流程录屏 | 能看到状态变化、页面衔接与完整路径 | 试用 / 订阅；需登录 |
| [The Component Gallery](https://component.gallery/) | 各设计系统的同类组件 | 横向比较不同系统如何命名、拆分和说明同一组件 | 免费 |
| [Design System Gallery](https://designsystem.gallery/) | 公开设计系统索引 | 从品牌、基础规范、组件到代码实现系统性浏览 | 免费 |
| [Land-book](https://land-book.com/) | 网站与落地页 | 适合观察首屏、内容节奏和模块组合 | 免费基础层；PRO 搜索/收藏 |

| 设计系统 | 最值得研究的部分 | 访问 / 许可 |
|---|---|---|
| [Material Design 3](https://m3.material.io/) | 跨端组件状态、动效、色彩和层级 | 官方免费文档 |
| [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) | 平台习惯、导航、手势、信息密度 | 官方免费文档 |
| [Fluent 2](https://fluent2.microsoft.design/) | 跨平台组件、设计 token、Figma 与代码协作 | 官方免费文档 |
| [Atlassian Design System](https://atlassian.design/design-system/) | 复杂协作产品的 foundations、components、patterns | 官方免费文档 |
| [Carbon Design System](https://carbondesignsystem.com/) | 企业级密集 UI、无障碍、token 与落地代码 | 开源；实现通常为 Apache-2.0 |
| [Adobe Spectrum](https://spectrum.adobe.com/) | 创意工具与复杂操作界面的组件行为 | 官方免费文档；实现另见开源仓库 |
| [GitHub Primer](https://primer.style/) | 内容密集产品、可访问性、组件文档 | 开源组件，具体许可见仓库 |

## 建议的观察题

- 同一个筛选器在消费产品、开发工具和企业后台里为什么不同？
- 页面如何呈现加载、空、错误、部分成功和权限不足？
- 视觉层级是靠颜色、字号、间距，还是靠运动与声音完成？
- 组件文档有没有说明“不该何时使用”？这通常比展示图更有价值。
