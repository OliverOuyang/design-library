# 交互与动效

动效的价值是解释变化、建立空间关系、确认操作和塑造气质。记录时先写“它解决了什么理解问题”，再写“它用了什么效果”。

## 动效拆解模板

每个案例用下面六项记录，比“丝滑”“很酷”更有用：

| 维度 | 要回答的问题 |
|---|---|
| Trigger | 什么动作或状态触发？ |
| Change | 用户需要理解什么变化？ |
| Timing | 时长、延迟、节奏、缓动如何安排？ |
| Space | 元素从哪里来、到哪里去，空间关系是否连续？ |
| Feedback | 是否明确告诉用户成功、失败、等待或可继续？ |
| Restraint | 减少动态偏好、低性能设备和连续操作时如何退化？ |
