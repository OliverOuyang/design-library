# 独立审核 SOP

> 文档职责：定义实施、过程审核与产出审核的独立性、固定输入、结论和复审规则。
> 当前状态：制度已批准；当前项目状态只见 07，历史审核结论只见 09。
> 适用范围：Standard 及更高影响的本库变更。
> 权威来源：06 验收矩阵与 09 审核记录。
> 最后更新：2026-07-30。
> 更新触发：审核角色、证据绑定或结论规则改变。

## 角色分离

| 角色 | 检查对象 | 不得做 |
| --- | --- | --- |
| 实施 | 按批准范围修改、自验、整理固定输入 | 自签产出通过或发布 |
| 过程审核 | 范围、职责、版本、真源、门禁、回滚 | 修改后直接批准自己的修改 |
| 产出审核 | 用户任务、事实、版权、检索体验、Taste 与边界 | 继承实施者的预期结论而不验证 |

Standard 改动至少要有独立产出审核；影响版权、资产删除、共享模板或发布声明的改动还需要独立过程审核。审核必须在新的任务／线程进行，以只读方式从固定输入开始；修复由实施者完成，内容变化后再开启新一轮复审。

## 固定输入与结论

审核包至少包含：目标和非目标、精确文件列表或 Git SHA、文件／资产哈希、相关检查结果、已知限制、回滚方式和本轮变更摘要。非 Git 阶段可用 `shasum -a 256` 输出与 `素材资产/素材清单与许可.md`；建立 Git 后以 SHA 优先。

结论只能为：

- `APPROVE`：无阻断问题，证据足够。
- `CONDITIONAL`：剩余事项明确、低风险且不改变核心语义；未关闭前不得称正式完成。
- `REJECT`：范围失控、事实／版权不可验证、关键检查缺失、用户任务／Taste 失败或无回滚锚点。

每轮将发现、固定输入、结论和复验结果追加到 09；不得覆盖旧轮次。

审核人对 [`09_共识交接与评审记录.md`](09_共识交接与评审记录.md) 追加该轮固定输入、发现和结论，属于审核产物的记录动作，不修改被审的治理控制、模板或资产；这种只追加的签署记录不使其绑定的结论失效。任何其他 09 内容修改仍按本 SOP 重新判定是否需要复审。

审核结论写入 09 后，07 可以仅更新当前状态、唯一下一步和指向该固定审核记录的引用。这种与签署结论一一对应的动态台账更新不改变被审控制、模板或资产，不使该轮审核失效；07 的迭代记录仍是台账，不承担审核发现与结论真源。
