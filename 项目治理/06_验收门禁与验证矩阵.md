# 验收门禁与验证矩阵

> 文档职责：定义可开始、可合并、可宣布完成的门禁、证据和停止条件。
> 当前状态：门禁制度已批准；每轮当前关闭状态只见 07，历史审核结论只见 09。
> 适用范围：本库内容、素材资产、启动包和治理改动。
> 权威来源：实际检查输出、02–05、07 与 09。
> 最后更新：2026-07-30。
> 更新触发：风险、工具、验收标准或证据路径改变。

| 场景 | 开始前 | 完成证据 | 阻断／停止条件 |
| --- | --- | --- | --- |
| 灵感条目／卡片 | 来源和可观察观察已知；否则标 candidate | 规则字段、标签、迁移与边界齐全 | 来源、观察或用途缺失，不升为精选 |
| 新本地素材 | 分类、权利、离线入口、5 项最小类计划 | 清单／Manifest／预览一致；哈希匹配；人工语义检查 | 许可不明、哈希不符、预览失效、重复或不满足最小类 |

| 领域／模板扩展 | 明确新增对象、真源、边界与迁移方式 | 参考／拆解／假设／资产可区分；入口、模板和收录规范可导航；独立过程与产出审核 | 把灵感当事实、把截图当可分发资产、把假设写成需求 |

## 最小可复算检查

```bash
shasum -a 256 素材资产/音效/*/*.wav
node --check 素材资产/assets-manifest.js
find 项目治理 -maxdepth 1 -type f -name '*.md' | sort
```

需要修改素材时，另人工验证预览页筛选、音频／motion 可加载、键盘／标签可达、静音或减少动态边界；需要修改文档时，检查 Markdown 链接和 00–10 责任映射。只读盘点与可丢弃草图不被本门禁阻断，但不得据此做发布或版权结论。
