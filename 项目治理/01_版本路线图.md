# 版本路线图

> 文档职责：定义版本对象、里程碑、依赖、准入与退场条件。
> 当前状态：版本策略已批准；实际阶段与当前锚点只见 07。
> 适用范围：审美与设计积累库。
> 权威来源：07 动态台账、素材清单哈希与未来 Git 历史。
> 最后更新：2026-07-30。
> 更新触发：版本策略、里程碑、依赖或版本锚点改变。

## 版本对象

| 对象 | 当前锚点 | 能证明什么 | 不能证明什么 |
| --- | --- | --- | --- |
| 灵感与模板文档 | 文件内容；Git 建立后以 commit 固定 | 某次的文字与结构 | 外部链接仍有效或内容质量已审核 |
| 本地音效／动效 | `素材资产/素材清单与许可.md` 中的 SHA-256 | 指定文件未漂移 | 某产品的使用许可或可访问性 |
| 预览库存 | `素材资产/assets-manifest.js` 与 `素材资产/预览/素材库预览.html` 的哈希 | 运行时清单和入口一致 | 新增素材的版权或体验质量 |
| 外部资料 | 10 中的来源记录 | 某次的采用理由 | 当前版本、可用性或许可未变化 |

## 路线与准入

| 阶段 | 范围 | 准入 | 退场条件 |
| --- | --- | --- | --- |
| `v0.1.0` 历史候选 | 双链路与启动包雏形 | 历史资料存在 | 仅作历史背景；旧 SHA 不可当作当前证据 |
| `v0.1.1` 种子库 | 30 个可预览素材、来源与哈希 | 本地完整性检查与历史独立审核 | 仍为 `SEED_REVIEWED_NOT_VERSIONED` |
| `v0.2.0` 治理重整 | 00–10、接续入口、门禁和台账 | 独立过程审核通过后，再由另一任务完成独立产出审核 | 建立 Git 初始快照，绑定当前内容 |
| 下一素材批次 | 第二个明确主题或现有分类扩展 | 先完成 02／03／06 中的收录与版权门禁 | 每类达 5 项、清单／Manifest／预览／审核一致 |

## 无 Git 锚点时的版本边界

当项目尚未初始化 Git 并完成首个可复核提交时，版本只能称为“本地证据锚点”或“未版本化种子”，不得称“正式发布”。Git 初始化后，每项实质变更必须以单一意图提交，并遵循项目上级的 Lore 提交信息协议；无需为了更改一行台账产生无意义提交。
