## 项目诊断

主类型是知识库／素材积累，辅类型是创意媒体和设计项目启动工作流。长期跨 Session、版权与外部来源、可复用启动模板使其达到 `Standard`；目前无生产写入、PII 或公开发布硬触发。地基是分类法、来源／许可、资产完整性、可迁移观察与启动包的设计合同。Taste 不是装饰：它要求条目清楚、克制、可检索，且不把参考误当复制答案。

## 权威顺序与状态边界

1. 本轮重新取得的文件、哈希、检查与独立审核证据。
2. 本目录已批准的合同、门禁、版本路线和台账。
3. 当前项目文件与根使用入口。
4. 稳定上下文、Agent 记忆与旧聊天。

`07` 是唯一动态状态真源；根 `更新记录.md` 仅保留面向使用者的变更摘要。`素材资产/assets-manifest.js` 是预览运行时库存真源，`素材资产/素材清单与许可.md` 是来源／许可／完整性真源，两者职责不同，不能互相替代。

除 Markdown 链接或绝对路径外，本目录中的反引号文件路径均以项目根目录为基准；在子目录内执行命令时先回到项目根，或显式调整相对路径。
