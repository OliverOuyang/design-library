# 收录规范

## 进入索引

灵感网站进入 `01_灵感索引`，应至少满足以下两项：

- 有稳定、持续更新或具有档案价值的内容。
- 能直接体验、检索、比较或拆解作品。
- 由原创团队、专业机构、正式出版物或可信社区维护。
- 在一个具体方向上明显优于普通聚合站。

## 进入个人卡片或组件拆解

个人内容进入 `03_个人卡片`，必须同时满足：

1. 能用一句话说清它是什么。
2. 能说清为什么值得留，不使用“高级”“好看”等空泛判断。
3. 有明确来源，或明确标注“来源未知”。
4. 至少有一个未来可迁移的场景。
5. 使用 3～6 个有效标签。

如果对象是 UI 组件、界面状态或交互流程，还必须补齐：它帮助用户完成的任务、触发动作、前后状态、加载／空／错／权限等必要状态，以及键盘、读屏、减少动态或替代反馈等适用约束。使用 [`UI组件与交互拆解模板.md`](UI组件与交互拆解模板.md)，不要把一张好看的截图伪装成可复用组件规则。

## 进入机会假设

产品构想、创意方向或脑暴内容可以进入收件箱或独立工作文件，但必须标记为 `hypothesis`，并至少保留：

1. 它来自什么问题、矛盾或跨界观察。
2. 哪部分是事实／证据，哪部分只是猜想或偏好。
3. 它为谁在什么场景下创造什么价值。
4. 一个反例或不成立条件。
5. 一个低成本、可撤销的验证动作。

机会假设不进入“精选”或项目 PRD，直到被真实研究、原型或使用证据验证。使用 [`机会假设与脑暴模板.md`](机会假设与脑暴模板.md)。

## 进入本地素材资产

音效、动效、动画、图标、插画、字体、3D、纹理或其他可执行／可再分发媒体进入 `素材资产`，必须同时满足：

1. 能离线播放、运行或打开；不能只留下外部链接。
2. 明确记录来源、许可证、获取日期与 SHA-256；本库原创项要写明生成/制作边界。
3. 被放入一个明确的最小分类，并能说明其动作语义或感官角色。
4. 同一最小分类一次性至少有 5 项；不足 5 项的候选先放 `00_收件箱`。
5. 在预览页或等价入口可被筛选；禁止把同一素材仅改名后重复计数。

网页截图、竞品录屏、UI 组件截图、品牌案例、摄影参考和文字摘录默认不满足“可再分发素材”条件，应进入索引、卡片或拆解，而非 `素材资产`。

## 评级

| 等级 | 名称 | 判断方式 |
|---|---|---|
| 1 | 存档 | 目前只是有趣，复用价值不明确 |
| 2 | 启发 | 有一个具体点值得记 |
| 3 | 可复用 | 能明确说出未来使用场景 |
| 4 | 基准 | 能作为同类设计的个人标尺 |

## 标签

标签使用固定槽位，数量控制在 3～6 个：

- `domain/`：领域，如 `domain/sound`、`domain/interaction`
- `object/`：对象，如 `object/button`、`object/onboarding`
- `mood/`：气质，如 `mood/playful`、`mood/restraint`
- `use/`：使用场景，如 `use/feedback`、`use/landing-page`
- `tech/`：实现方式，如 `tech/web-audio`、`tech/css`
- `theme/`：母题，如 `theme/rhythm`、`theme/materiality`

不要使用只有自己当下才懂的标签，也不要把“好看”“高级感”当标签。

## 去留判断

以下内容优先删除或留在收件箱：

- 只有气氛，没有可观察细节。
- 只有截图，没有上下文与来源。
- 与已有内容重复，只是视觉换皮。
- 连续 8～12 周没有再看，且无法说明用途。
