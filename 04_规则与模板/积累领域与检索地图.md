# 积累领域与检索地图

> 文档职责：把“做产品、练审美、头脑风暴”转成可检索的积累入口；不承担实时状态或外部资料真源。
> 适用范围：审美与设计积累库。
> 权威来源：`01_灵感索引`、收录规范、个人卡片与项目启动包。
> 更新触发：领域边界、检索习惯或对象类型改变。

## 先选你要解决的问题

| 想推进什么 | 优先领域 | 该留下什么 | 不要误当成 |
| --- | --- | --- | --- |
| 产品任务、信息架构、服务体验 | 产品与体验、UI与组件 | 用户任务、流程、状态、取舍 | 需求已被验证 |
| 控件、页面状态、反馈机制 | UI与组件、交互与动效 | 触发、前后状态、异常与无障碍约束 | 可直接抄的组件 |
| 品牌气质、创意概念、叙事 | 品牌与创意、艺术与跨界 | 概念张力、参考原则、反例、试验 | 客户已经认可的方向 |
| 构图、排版、色彩、图像、材质 | 视觉与素材、艺术与跨界 | 视觉观察、适用场景、版权边界 | 可再分发素材 |
| 语气、文案、阅读节奏、叙事 | 文字与文学 | 语境、结构、不可替换之处、迁移条件 | 可直接复制的文案 |
| 声音、动效、节奏与感官反馈 | 声音与音效、交互与动效 | 动作语义、时机、强度、替代反馈 | 某产品已通过无障碍验证 |
| 发散新机会 | 产品与体验、品牌与创意、艺术与跨界 | `hypothesis`、证据、反例、低成本试验 | 事实、用户需求或路线承诺 |

## 四种对象，四条路径

1. **参考（reference）**：外部链接、截图或作品；进入索引或收件箱，说明为什么值得继续看。
2. **拆解（breakdown）**：已形成自己的观察；进入个人卡片，说明任务、结构、状态、迁移点和边界。
3. **机会假设（hypothesis）**：由观察引出的可验证方向；使用机会假设模板，等待研究或原型证据。
4. **可执行资产（asset）**：有明确使用权、来源、完整性和本地入口的文件；才进入 `素材资产`。

同一外部案例可以产生“参考 + 拆解 + 假设”，但三者必须互相链接、不能重复写成同一事实。只有实际获得权利的文件才能再成为 `asset`。

## 检索配方

优先组合 `object/` + `use/` + `mood/` 或 `theme/`，例如：

- `object/destructive-action` + `use/recovery`：高风险操作如何可逆。
- `object/long-form` + `mood/editorial`：长内容如何有层级与节奏。
- `object/error-message` + `use/guidance`：错误如何帮助恢复而非指责。
- `theme/physicality` + `use/feedback`：如何建立有触感的反馈。

不要把“高级感”“好看”“灵感”当成检索词；它们不能指向可执行的观察或判断。
