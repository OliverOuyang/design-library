# 个人卡片

这里存放你真正看过、拆过、并形成判断的内容。

一张卡片对应一个明确对象：一个组件、一个页面状态、一次交互、一组声音、一个产品流程、一段文字或一个作品。不要把整个网站机械地复制成卡片。

文件名建议：

```text
领域-日期-简短名称.md
```

例如：

```text
声音-20260730-Cuelume交互提示音.md
交互-20260730-按钮按压与释放.md
文字-20260730-克制的错误提示文案.md
组件-20260730-高风险删除确认.md
流程-20260730-首次引导的进度反馈.md
```

复制 [`个人卡片模板.md`](../04_规则与模板/个人卡片模板.md) 开始记录。
